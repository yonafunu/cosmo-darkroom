Comparison

COSMO engines and RC-Astro

Three COSMO tools run either an in-house network or, from a licensed installation, the RC-Astro product that does the same job. Each comparison below shows the same linear stack passed through the same tool, once with each engine.

Method

  • Same input: the stack after the Background step (GraXpert), in its linear state.
  • Default settings for both engines, as COSMO sets them when the engine is chosen.
  • Same display: COSMO's Stretch step (automatic) is computed on the input and applied unchanged to the input and both results, then the same Saturation. Star removal is shown on the stretched image the separation works on, with the same Saturation.
  • Crops at 100 % unless stated; the buttons switch between the two engines and before / after each one.

Separation of the stars from the nebula: the nebula layer, without its stars. Separate stars tool page.

BlurXTerminator, NoiseXTerminator and StarXTerminator are products of RC-Astro, LLC. COSMO runs them through the RC-Astro command-line tool when they are installed and licensed on the computer; they are not part of COSMO.
