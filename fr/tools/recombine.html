Étoiles

Outil Recombine

Remet les étoiles sur la nébuleuse, avec une contribution réglable.

Comment s'en servir

  1. Ouvrir Tools et cliquer l'outil : il s'ajoute après l'étape choisie.
  2. Bouger ses réglages : l'image suit pendant le geste (Live preview).
  3. Apply garde le résultat. Before / after compare à tout moment.

Réglages

Screen / Add
Screen : pour une nébuleuse étirée (ne sature jamais). Add : pour des couches linéaires.
Star brightness
La contribution de la couche d'étoiles.

Quand s'en servir

Après une séparation, une fois la nébuleuse et les étoiles réglées chacune.

Image

Travaille sur une image linéaire ou étirée.
