Image étirée

Outil Dark structures

Creuse les bandes de poussière, les globules et les nébuleuses sombres.

Comment s'en servir

  1. Ouvrir Tools et cliquer l'outil : il s'ajoute après l'étape choisie.
  2. Bouger ses réglages : l'image suit pendant le geste (Live preview).
  3. Apply garde le résultat. Before / after compare à tout moment.

Réglages

Amount
De combien les structures sombres sont creusées.
Layers
Les structures sombres les plus larges prises en compte : plus de couches atteint de plus grandes nébuleuses sombres.
Mask
Everywhere, Bright parts (l'objet, pas le fond de ciel) ou Dark parts. Les étoiles n'en font pas partie.
Threshold
Où commence le masque, du fond de ciel (0 %) à la partie la plus brillante de l'objet (100 %).

Quand s'en servir

Quand les bandes de poussière et les nébuleuses sombres paraissent plates sur le fond lumineux.

Image

Travaille uniquement sur une image étirée.
