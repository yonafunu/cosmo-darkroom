Image linéaire

Outil Background

Retire les gradients de pollution lumineuse et neutralise le fond de ciel.

Comment s'en servir

  1. Choisir l'étape dans la séquence, ou ajouter l'outil depuis Tools.
  2. Le régler, puis Preview : l'étape est calculée sans être appliquée.
  3. Apply garde le résultat ; sinon changer les réglages et relancer Preview.

Réglages

Remove gradients
Modélise la lueur du ciel et les gradients de pollution lumineuse, et les soustrait.
Samples
Le nombre de points de ciel qui nourrissent le modèle : plus il y en a, plus il suit les gradients fins.
Smoothing
Le lissage du modèle de gradient : plus il est fort, mieux les nébulosités faibles sont préservées.
Neutralize the sky colour
Décale chaque couleur pour que le fond de ciel soit gris neutre.
Balance the colours on the stars
Met le rouge et le bleu à l'échelle pour que l'étoile typique soit blanche. À décocher si l'on utilise Colour calibration.

Quand s'en servir

Juste après le recadrage, tant que l'image est linéaire. Un gradient étiré est bien plus difficile à retirer.

Image

Fait pour une image linéaire ; utilisable sur une image étirée.
