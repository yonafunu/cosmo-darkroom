Étoiles

Outil Reduce stars

Rétrécit les étoiles, halos compris, ou les retire.

Comment s'en servir

  1. Choisir l'étape dans la séquence, ou ajouter l'outil depuis Tools.
  2. Le régler, puis Preview : l'étape est calculée sans être appliquée.
  3. Apply garde le résultat ; sinon changer les réglages et relancer Preview.

Réglages

Reduce / Remove
Rétrécir les étoiles, ou les effacer.
Star size
Chaque étoile rétrécit autour de son centre, halo compris, en gardant son profil doux.
Removal
Efface les étoiles, vers l'image sans étoiles. Instantané.
Result / Starless / Stars only
Ce que l'image montre pendant le réglage.

Quand s'en servir

Quand les étoiles encombrent la nébuleuse. Travaille sur toute l'image, ou sur la couche d'étoiles après une séparation.

Image

Travaille sur une image linéaire ou étirée.
