Image linéaire

Outil Colour calibration

Règle les gains des trois canaux de couleur : d'après le profil de l'équipement, les étoiles de l'image, ou le catalogue Gaia DR3.

Comment s'en servir

  1. Choisir l'étape dans la séquence, ou ajouter l'outil depuis Tools.
  2. Le régler, puis Preview : l'étape est calculée sans être appliquée.
  3. Apply garde le résultat ; sinon changer les réglages et relancer Preview.

Réglages

Equipment
Applique les gains déjà mesurés pour ce capteur et ce filtre.
Image stars
Rend blanche l'étoile médiane de l'image. N'a besoin de rien d'autre.
Gaia
Donne à chaque étoile la couleur que le catalogue Gaia DR3 lui connaît ; les gains sont ensuite enregistrés comme profil de l'équipement.

Quand s'en servir

Après Background, avant de séparer les étoiles. Une fois le capteur et le filtre mesurés, il prend une fraction de seconde.

Image

Travaille uniquement sur une image linéaire.
