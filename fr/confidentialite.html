Confidentialité

Données et confidentialité

Données traitées par ce site et par le logiciel.

Ce site

Il n'a ni compte, ni formulaire, ni cookie. Les polices sont celles de votre appareil ; les images et la vidéo sont servies avec les pages.

Les visites sont comptées avec GoatCounter, une mesure d'audience libre qui ne dépose aucun cookie et ne garde aucune donnée personnelle. Pour chaque page vue, il reçoit l'adresse de la page, le site d'où vous venez, le navigateur, la taille de l'écran et le pays déduit de l'adresse IP ; l'adresse IP elle-même n'est pas conservée. Les clics sur les boutons de téléchargement, de soutien et Facebook sont comptés de la même façon. Les statistiques ne sont visibles que de l'auteur de COSMO. Bloquer les domaines goatcounter.com et gc.zgo.at, comme le font beaucoup de bloqueurs de publicité, arrête le comptage.

Le site est hébergé par GitHub Pages, et les installateurs sont téléchargés depuis GitHub. Comme tout hébergeur, GitHub reçoit les données techniques d'une connexion (adresse IP, page ou fichier demandé) pour pouvoir répondre ; voir la déclaration de confidentialité de GitHub.

Les liens vers Facebook sont de simples liens : ces pages ne chargent aucun script, bouton ou traceur de Facebook. Facebook ne reçoit votre visite que si vous suivez l'un d'eux.

Le logiciel

Tous les calculs se font sur votre ordinateur. Vos images ne sont envoyées nulle part.

Deux outils interrogent le catalogue d'étoiles Gaia de l'Agence spatiale européenne, et seulement quand vous le demandez : la calibration des couleurs sur Gaia, et la mesure de profondeur de la fenêtre Analysis. Seules les coordonnées du champ partent. La réponse est gardée sur votre disque : un champ n'est demandé qu'une fois.

Au démarrage, au plus une fois par jour, COSMO demande à GitHub le numéro de la dernière version publiée, pour vous signaler qu'une version plus récente existe. Rien ne part sur vous ni sur vos images ; GitHub reçoit les données techniques de la connexion. Rien ne s'installe tout seul. La vérification se coupe dans Help › Check for updates at startup.

GraXpert et les moteurs RC-Astro, si vous les utilisez, sont des logiciels à part : leurs téléchargements de modèles et leurs vérifications de licence suivent les conditions de leurs éditeurs. COSMO ne stocke aucune clé de licence.
