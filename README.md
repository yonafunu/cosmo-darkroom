# COSMO Darkroom

Free software for stacking and processing deep-sky images.

- **Website**: https://yonafunu.github.io/cosmo-darkroom/
- **Download**: [latest release](https://github.com/yonafunu/cosmo-darkroom/releases/latest) — macOS (Apple Silicon) and Windows installers
- **Questions and reports**: [issues](https://github.com/yonafunu/cosmo-darkroom/issues)

This repository holds the website and the installers. COSMO Darkroom is free to use; it is not open source.
