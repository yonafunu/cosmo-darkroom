Linear image

Sharpen tool

Tighter, rounder stars and sharper detail (deconvolution).

ExperimentalCOSMOSharp, the in-house network of this tool, is experimental and not recommended for finished images: defects remain on some images. The tool can also run with RC-Astro BlurXTerminator, from your own licensed installation. The Classic method (Richardson–Lucy) does not use it.

How to use it

  1. Select the step in the sequence, or add the tool from Tools.
  2. Set it, then press Preview: the step is computed without being applied.
  3. Press Apply to keep the result, or change the settings and preview again.

Settings

AI / Classic
The trained model, or a classic deconvolution.
Star tightening
How much the stars are tightened.
Nebula sharpening
How much the detail of the nebula is sharpened.
Iterations
Classic method: the number of deconvolution passes.
Noise protection
Classic method: keeps the noise from being sharpened.

When to use it

On the linear image, before Denoise: sharpening needs the real shape of the stars, noise included.

Image

Works only on a linear image.
